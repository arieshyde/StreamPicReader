| 项 | 内容 |

## 4. Grill 问答记录（要点摘录）

- Q1：C — 桌面 + iOS/Android 全覆盖。影响：Electron 出局。
- Q5：话内连续无缝垂直滚动；底部“上一话/下一话”按钮：第一话显示“第一话”（无响应），最后一话显示“没有了”（无响应）。
- Q7：虚拟滚动/懒加载；单话约 300 张，每张 1~3MB；打开后 3~5 秒内可读。
- Q9：每作品只记一个话一个位置；作品页高亮上次话；进入该话恢复滚动位置。
- Q18：取消“库根目录”概念，改为逐个添加作品文件夹；作品名 = 目录名；路径存软件配置目录。
- Q20：续读记录存作品文件夹内 `.streamreader.json`，随作品迁移。

## 6. 最终技术栈决策

**Tauri 2 + React + TypeScript + Rust**

- 前端（Web）：书架页 / 话列表页 / 阅读页（虚拟滚动）、深色主题、i18n（中/EN）。
- 后端（Rust）：目录扫描与图片过滤、话/图自然排序（提取数字）、CBZ/ZIP 解码、
  设置 JSON（软件配置目录）与续读记录（作品内 `.streamreader.json`）读写、图片流式供给。
- 平台：Windows 优先，随后 macOS / Linux，移动端（iOS/Android）后期基于 Tauri 2 移动端支持跟进。
